# How to Generate GRPC Files

All .cc and .h files are generated by grpc in this folder. Please refer to
[Audio2Face-3D Samples Proto](https://github.com/NVIDIA/Audio2Face-3D-Samples/tree/main/proto)
for the latest proto files, and follow the instructions.

More information can be found in
[Audio2Face-3D Microservice GRPC documents](https://docs.nvidia.com/ace/audio2face-3d-microservice/1.3/text/interacting/a2f-rpc.html).
