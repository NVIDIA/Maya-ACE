# Maya ACE &middot; [![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE.txt)

**High-Quality Audio-Driven Facial Animation with NVIDIA Audio2Face-3D SDK and ACE Service**

[Maya-ACE](https://github.com/NVIDIA/Maya-ACE) is a powerful Maya plugin that brings NVIDIA's Audio2Face-3D technology directly to your creative workflow.
It offers two complementary solutions: local GPU processing via the Audio2Face-3D SDK for maximum performance and control, and cloud-based processing through the Audio2Face-3D NIM for scalability.
