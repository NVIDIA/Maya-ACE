# Requirements

- [Autodesk Maya](https://www.autodesk.com/products/maya/overview) 2023, 2024(recommended), or 2025
- Microsoft Windows 10 64bit or 11
- Internet connection
- [API key](https://build.nvidia.com/nvidia/audio2face-3d/api) or a private [Audio2Face-3D Service](https://catalog.ngc.nvidia.com/orgs/eevaigoeixww/teams/animation/helm-charts/a2f-service)
- Python 3.10 (to build and run test codes)

Other Maya versions and platforms can be supported in the future.
